Закрывать автоматически
В пользовательских настройках (Ctrl+Shift+P → Preferences: Open User Settings (JSON)):
{
    "workbench.colorTheme": "Dark Modern",
    "makefile.configureOnOpen": true,
    "git.openRepositoryInParentFolders": "never",
    "C_Cpp.intelliSenseEngine": "disabled",
    // Терминалы убиваются, как только они не нужны (не показываются/не в фокусе)
    "terminal.integrated.enablePersistentSessions": false,
    "clangd.path": "c:\\Users\\john\\AppData\\Roaming\\Code\\User\\globalStorage\\llvm-vs-code-extensions.vscode-clangd\\install\\23.1.0\\clangd_23.1.0\\bin\\clangd.exe"
}

Это убирает «накопившиеся» вкладки терминалов — в том числе gdb-server.

Не загромождать панель терминалов
У Cortex-Debug есть параметр, куда выводить лог gdb-сервера. Проверьте в вашей версии:

Ctrl+Shift+P → Settings → поиск gdb server (в фильтре cortex-debug)

Обычно называется cortex-debug.gdbServerTerminal и принимает значения вида internal / integrated. Значение internal показывает вывод во встроенном терминале расширения, а не в общей панели терминалов.
